Q1D1Intermediate

Objective: Translate business problems into Claude-based AI solutions

Scenario

A retailer's COO asks for "AI to cut returns fraud." The team has years of labeled structured transaction data, needs a decision in under 50 ms at checkout, and also has free-text return notes that analysts rarely read.

Question

What is the best first move?

  1. ABuild an autonomous Claude agent that reviews every return and blocks suspicious ones.
  2. BAssess task fit: use conventional scoring/rules for the structured, latency-critical decision, and evaluate Claude only for the unstructured return-note signal.
  3. CSend each customer's full transaction history to the largest model on every return.
  4. DDelay the project until models offer lower latency than 50 ms.
Show answer & explanation

Correct answer B

Explanation

The core decision is structured, labeled, and latency-bound — a classic fit for conventional ML/rules. Claude adds value on unstructured text where variability is high.

Why not the others

A hands an irreversible, latency-critical decision to an autonomous LLM with no case for it. C is slow and costly and sends excess data. D assumes Claude must own the entire flow.

Architectural principle

Use LLMs where input variability is high; keep deterministic or classic-ML paths where they fit better.

Reference

Prep course Lesson 1; https://www.anthropic.com/research/building-effective-agents

Q2D1Intermediate

Objective: Align solutions to business value pillars (efficiency, transformation, productivity, cost, performance SLAs)

Scenario

A hospital network has no overnight patient-intake service today. It wants Claude to offer 24/7 intake in six languages.

Question

Which framing and metric best match the value being created?

  1. ACost: dollars saved per intake call.
  2. BProductivity: nurse hours saved per week.
  3. CTransformation: a capability that did not exist — measure coverage (hours/languages served), completion rate, and escalation quality.
  4. DPerformance SLA: average response time of the chat widget.
Show answer & explanation

Correct answer C

Explanation

The primary value is a new capability, so the success metrics should reflect coverage and outcomes of that new service rather than savings against a baseline that doesn't exist.

Why not the others

A and B assume a baseline process being made cheaper or faster. D is a supporting NFR, not the value case.

Architectural principle

Pick the value pillar that matches the sponsor's real objective, then choose metrics to match.

Reference

Exam Guide §6 D1; Prep Lesson 4

Q3D1Advanced

Objective: Translate business problems into Claude-based AI solutions

Scenario

Legal operations asks to "automate contract review." Attorneys must remain accountable; there is a clause playbook for NDAs only; a labeled sample of 200 NDAs exists.

Question

Which scope is the most defensible first release?

  1. AFlag and extract playbook-defined clause deviations in NDAs with attorney review, measured on recall against the labeled set.
  2. BNegotiate and redline all contract types autonomously.
  3. CSummarize every contract in the repository into one paragraph.
  4. DReplace attorney review for contracts under a value threshold.
Show answer & explanation

Correct answer A

Explanation

It's a thin slice with data, a playbook, a measurable target, and human accountability.

Why not the others

B and D remove accountability and exceed the available playbook/data. C is measurable on nothing and creates no decision value.

Architectural principle

Scope to the thinnest slice with ground truth, measurable success, and human oversight.

Q4D1Advanced

Objective: Translate business problems into Claude-based AI solutions

Scenario

A sponsor wants contract-risk analysis of 100-page documents to be "instant, perfectly accurate, and cheap."

Question

What should the architect do?

  1. AUse the most capable model for every request and promise the sponsor all three goals.
  2. BQuietly prioritize accuracy and let latency slip.
  3. CShorten documents until all three goals look attainable.
  4. DSurface the conflict as explicit trade-offs and propose tiers — e.g., fast low-cost triage, plus deeper asynchronous analysis with review — quantified with measured numbers.
Show answer & explanation

Correct answer D

Explanation

Conflicting NFRs must be made visible and resolved by the stakeholder, with options that map to levers (model tier, caching, async).

Why not the others

A over-promises. B makes a hidden decision for the business. C silently changes scope.

Architectural principle

Expose competing non-functional requirements and let the business choose among priced options.

Q6D1Advanced

Objective: Translate business problems into Claude-based AI solutions

Scenario

A tax-software vendor must produce identical results for identical inputs; calculations follow fixed published formulas; customers upload messy PDFs of source documents.

Question

Which design is most appropriate?

  1. AHave Claude compute the tax figures directly from the PDFs.
  2. BHave Claude compute figures twice and accept them when both runs agree.
  3. CUse Claude to extract inputs from documents with validation, and compute tax in deterministic code; optionally use Claude to explain results.
  4. DFine-tune a model on past returns so it learns the formulas.
Show answer & explanation

Correct answer C

Explanation

Extraction from variable inputs suits an LLM; fixed formulas and reproducibility call for deterministic code.

Why not the others

A and B put arithmetic and rules in a probabilistic component; agreement isn't correctness. D is an unnecessary path that still isn't deterministic.

Architectural principle

Keep deterministic logic deterministic; use LLMs for language-heavy, variable tasks.

Q7D1Intermediate

Objective: Select appropriate architectural patterns (workflow, agentic, augmented LLM)

Scenario

A nightly process extracts eight fields from invoices that arrive in three known layouts. Nobody waits on the result.

Question

Which pattern is best?

  1. ARoute by layout to a layout-specific extraction prompt, run as a non-interactive batch with schema validation.
  2. BA fully autonomous agent that decides how to process each invoice.
  3. CA single prompt handling all layouts, run synchronously per invoice with the largest model.
  4. DA multi-agent debate among several extraction agents per invoice.
Show answer & explanation

Correct answer A

Explanation

Known categories + no latency pressure = routing/workflow with batch for cost efficiency.

Why not the others

B and D add cost and variance without need; C ignores layout-specific tuning and the cost advantage of batch.

Architectural principle

Use the simplest pattern that meets the requirements; match processing mode to the SLA.

Three parallel worker agents update a shared project plan and sometimes produce conflicting edits, leaving the plan inconsistent.
