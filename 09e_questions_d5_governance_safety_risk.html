Q99D5Advanced

Objective: Implement guardrails and safety controls

Scenario

An email-triage agent reads inbound customer emails and can send external emails. A penetration test shows an email with hidden instructions made the agent forward internal data.

Question

Which response is best?

  1. ALengthen the system prompt with stronger warnings.
  2. BSwitch to a larger model.
  3. CAsk users to avoid suspicious emails.
  4. DRemove the unconstrained send capability (use draft-only plus approval), authorize tool calls outside the model, restrict egress, treat email content as untrusted data, and add screens and monitoring.
Show answer & explanation

Correct answer D

Explanation

Layered controls with preventive capability reduction and enforcement outside the model address indirect injection.

Why not the others

A and B rely on model behavior; C shifts burden to users.

Architectural principle

Don't assume prompting alone is sufficient.

Reference

https://platform.claude.com/docs/en/test-and-evaluate/strengthen-guardrails/mitigate-jailbreaks

Q100D5Intermediate

Objective: Implement guardrails and safety controls

Scenario

An assistant fetches web pages and passes their text to Claude.

Question

How should the third-party content be delivered?

  1. AAppended to the system prompt.
  2. BIn tool-result content with its origin labeled, with a policy stating such content is untrusted data that must not override instructions.
  3. CAs a message from the user role containing the text verbatim, unlabeled.
  4. DHidden in the first few tokens of the conversation.
Show answer & explanation

Correct answer B

Explanation

Treating retrieved content as tool results (data) with provenance, and stating the policy, reduces the chance it's treated as instructions.

Why not the others

A and C elevate untrusted text to instruction channels; D obscures provenance.

Architectural principle

Separate trusted instructions from untrusted data.

Reference

Mitigate jailbreaks and prompt injections docs
